## 3. Fluxo de comentários aprovado em conversa (sem nova plataforma)
**Caixa editorial:** `contact.passportradio@proton.me`.  
Fluxo de operação proposto e decidido:
1. Visitante escreve o comentário com apelido e identificação da matéria.
2. Comentário é encaminhado para a caixa Proton Mail, para leitura privada.
3. **Mr. Nomad** lê e aprova/rejeita.
4. **Somente depois de ordem expressa**, a **Work** insere o comentário aprovado na matéria/estrutura de comentários e prepara a alteração no repositório para autorização de publicação.
5. Quando essa alteração for publicada com autorização, o comentário passa a estar visível.

**Não afirmar que mover um e-mail para APROVADOS publica automaticamente. Não afirmar que a Work já está conectada ao Proton ou já implementou esse processo.**  
Se a interface de envio for feita via `mailto:`, ela abre o aplicativo de e-mail do leitor; **não** simular que envia diretamente ou que a leitura acontece dentro do site. A experiência final e seus testes dependem de futura ordem de implementação.
