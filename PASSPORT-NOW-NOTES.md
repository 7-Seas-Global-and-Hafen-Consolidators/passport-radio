# Passport Now™

- Counts active Passport playback events only.
- Public UI shows the 15-minute unique listener aggregate as `OUVINDO AGORA`.
- Tracks playback events without transmitting stream/provider URLs.
- Home and `anuncie.html` read the aggregate.
- `radio.html` contributes playback heartbeats through `passport-radio-global.js`.
- Existing player engines, playlists and tunnel source configuration remain unchanged.
